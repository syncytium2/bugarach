# The canonical surname is Gregers Hansen, and three docs treat it as Hansen

> **Actionable now** — needs no new source. Deliberately not done on 2026-09-10 because changing an
> attribution across the glossary, the README and the lineage doc deserves its own review rather
> than riding along in a handoff.

## What two primary sources say

- The volume's contents listing (`radar/iee_conf_105_1973_CONTENTS_ONLY.pdf`):
  *"GREGERS HANSEN,V.: Constant-false-alarm-rate processing in search radars"*.
- IEEE's own authority record (`radar/gregers_hansen_AUTHOR_PROFILE_ieee.pdf`):
  **V. Gregers Hansen** — *"Also published under: Vilhelm Gregers Hansen, V. Hansen, V. G. Hansen"*,
  Raytheon Company, Wayland MA.

## What is and is not wrong

⚠ **Not an error — a variant.** IEEE lists *V. G. Hansen* as a form he genuinely published under, so
`Hansen VG` is documented rather than fabricated. An earlier draft of this finding said we had been
citing it "wrong"; that was too strong and is corrected in [`lit_needed.md`](../lit_needed.md).

**What is true is narrower:** the canonical form is **Gregers Hansen**, and treating `Hansen` as the
surname inverts a compound one. A repo whose whole detector-history apparatus exists to get
attribution right should use the canonical form.

## Where it appears

`GLOSSARY.md` (the CFAR vocabulary block), `README.md` (Licensing & citations), and
[`detector_history.md`](../detector_history.md) §4. **Includes the 1980 paper already on the shelf**
— cite it as **Gregers Hansen & Sawyers**.

## Do not

Do **not** touch §4's *origin* column in the same pass. Whether 1973 or 1980 is the origin is a
separate, still-open question —
[`nobody has read Hansen 1973`](2026-09-10-nobody-has-read-hansen-1973.md) — and the name fix must
not be mistaken for a ruling on it.

## Closes when

The three docs use the canonical form, the shelf filename convention is consistent with it, and
nothing about the origin column has moved.
