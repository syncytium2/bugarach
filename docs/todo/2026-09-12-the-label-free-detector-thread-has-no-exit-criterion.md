# The label-free detector thread has no exit criterion, and it needs one before the next tier

The thread has a clear entry condition — twenty-two hours of baseline recordings nobody can annotate,
and every learned number in this project fitted on a generator that plants one event width, uniform
participation and no recurring assemblies. It has no condition under which it stops.

## Why that is a live risk rather than a tidiness point

The first design was killed by its own review. The replacement is a screen whose verdict rule two
review rounds could not close, and which now waits on measurements. Each of those steps was the right
answer to the step before it. None of them is a test the **approach** can fail.

The screen can produce an answer that should stop the thread, and it would not be read that way
without a rule agreed in advance: **if every candidate that does not leak also fails to destroy
coordination, self-supervision against a surrogate is not available on this data.** That is a real
possible outcome — see
[the join](2026-09-12-join-the-leak-results-to-the-destruction-results.md), where the candidates
surviving the leak detector cluster at one frame of displacement, and do-nothing survives everywhere.

## What an exit criterion would look like

Written before the numbers are read, so it cannot be adjusted to fit them:

- **Viable:** at least one candidate leaks no more than do-nothing at a displacement where it removes
  planted coordination, on both folders. The thread proceeds to the model tier.
- **Narrowed:** viable on one folder only. The thread proceeds, and every claim names the folder.
- **Stopped:** no candidate is viable anywhere. The fallbacks are then the simulator-trained models
  with [their measured transfer penalty](2026-09-10-the-design-trains-quiet-and-deploys-busy.md), and
  the six hand-written detectors, and the finding is that a surrogate objective cannot be built on
  this preparation's event extraction — which is worth writing up, because it is a real result about
  the data rather than a failure of the thread.

## What this is not

Not an argument to stop. The thesis that survived the first review still holds: a surrogate objective
is the only route in sight to a learned detector that has not merely learned this project's simulator.
The point is that a thread with no stopping rule cannot distinguish "not yet" from "no", and this one
has already spent two reviews and an overnight run without ever being able to.

## Closes when

The exit criterion is written down, before the verdict rule is applied to the measurements.
