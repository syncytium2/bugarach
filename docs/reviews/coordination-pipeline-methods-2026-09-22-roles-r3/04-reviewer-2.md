| F2 | Test recordings, elevated-rate test (l.143–144); Table 3; `score.py` hot_fa | [PIPELINE] **The elevated-rate test counts calls, so a longer merge gap can hide more firing.** The probe counts calls that overlap the block (one call spanning the whole block counts once).
