1. §The rule, eq 8 (line 47–50), and §How the code arrives (line 163) · **The bound the proposal relies on is not in the code it plans to copy.** It copies only `coactivity()` and `control()`. The clamp to [S_MIN, S_MAX] lives in `modulate()` (clamor/malsburg1986.py:276), which is not copied. At the paper's q₀ = 0.01, one Co = +1 step from rest takes s to 0.0220, past S_MAX = 0.0216. `control()` there returns q = −0.00085, which is negative. After that, coincidences push the coupling down and near-misses push it further up, with q growing more negative each time: sign reversal and runaway. So "every coupling stays within 80 %" is false for the functions as specified. Even with the clamp added, clamor's own record says q₀ = 0.01 is 1.04× the half-range (CLAIMS.md item 2; `Q0_OVER_HALF_RANGE`). One coincidence then puts the entry on the clamp, where q = 0 forever. So at q₀ = 0.01, *D* records the first update or two per pair, not an accumulation. q₀/12 and q₀/√12 never overshoot. · blocking · Copy the clamp too, or state it and write it. Drop q₀ = 0.01 from the grid, or keep it only as a known-degenerate arm. State that the clamps absorb. · yes (computed: s = 0.02200 > 0.0216, q = −0.00085)

5. §Why that point…rate-neutral (lines 73–79) · **Rate-neutrality holds for the mean only, and every readout depends on more than the mean.** Under independence the expected update is zero, and exactly so, not "to first order": the process is a martingale because q depends only on the past. The misplaced caveat hides the real problem. Var(*D*_ij) grows with the number of pair updates, which scales with n_i·n_j and with burst multiplicity. The Frobenius norm, the leading eigenvalue, the "positive part" handed to community detection, and E(t) all respond to variance. Under the null, busy pairs carry the largest |*D*| of either sign, so readout 2 will group busy cells. · blocking · Either standardise *D* per pair by its null SD, estimated from surrogates, or state that rate-neutrality is first-moment only and show readouts 2 and 3 on a z-scored *D*. Delete the "to first order" parenthesis, or replace it with the variance statement. · yes (derivation; clamor `control`)

6. Readout 1 null (lines 99–102) · **Circular shift throws away structure the real data have at slower timescales, so readout 1 can come out significant for reasons unrelated to fast coordination.** The measured slow shared modulation is 3.2× the independent level on lab fast, and 2.4× with CoactDetect episodes removed (goal page, 2026-09-17 line; `learned/slow_comodulation`). Circular shift removes it; within ±*w* the real data keep it. Its effect on the *mean* of *D* cancels (flat over ±*w*, zero-integral kernel), but it adds pair updates. That raises Var(*D*), and the Frobenius norm and eigenvalue rise above the null with no coordination at the *w* scale. Population events do the same, and the field is known to have them. So readout 1 can hardly come out null. · blocking · Add a null that keeps slow shared modulation, e.g. a rigid or interval shift bounded by a few seconds, or say explicitly which structure the test rejects. This is exactly the screen's subject, so it also bears on finding 9. Positive/negative control: a simulated field with shared minute-scale rate drift and no fast coordination must *not* reach significance. · yes (goal page line 74)

7. §The width (lines 85–91) and the whole kernel · **At the low end of the sweep the positive lobe is only the same-frame lag, which is where artifacts sit.** At *w* = 2 jitters on fast, K = 2 frames and the kernel is [+1, 0, −0.5] by lag.
