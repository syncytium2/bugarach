# Murderboard run — site/index.html and site/landscape.html

## The problem

The public front page named CICADA as prior art in its closing section and never
said that one of the six detectors in the figure at the top of the same page **is**
CICADA's method. A reader met six lanes — LoCo, locust, binned SCE, CoactDetect,
rate+context, SPIKE-synch — and a paragraph crediting a tool whose name appeared
nowhere among them.

The gap was created by an attribution fix. `ui/app.py` renames the `cicada`
detector to **locust** on display, and its comment says why: *"Showing a user
another lab's tool name for a modified port was the one attribution item Tony did
not wave off (2026-08-24)."* That is right. But the rename moved the Cossart lab's
name off the figure without putting the derivation anywhere a reader of the page
would find it, so the honest half shipped and the other half did not. The README's
licensing table and citation list have been correct throughout; the front page was
the surface that disagreed with them.

The same pass carried a second instruction: the landscape page stated absences as
fact — *"nobody trains a network to emit assembly membership"*, *"nobody detects the
coordinated event itself…"* — where what is actually known is that a search did not
find one. That page already carries a standfirst confessing that an earlier version
asserted exactly such an absence and was overturned by reading three papers, so the
remaining "nobody"s were the same defect the page was written to correct.

## What was found

Seven findings, of which three were introduced by the fixes themselves and caught on
re-render. The two that would have shipped something false:

**A citation carried the wrong licence.** The draft cited CICADA as
`Zenodo 10.5281/zenodo.10041434 (MIT)`. The Zenodo record is **CC-BY-4.0**; the
GitLab source is MIT. Both were verified against the record and the repository, not
against this repo's own README. Two artifacts, two licences, and putting one beside
the other's identifier asserts something untrue about a third party's work. The
licence was dropped from the citation — it belongs in the README's licensing table,
where it is correct and correctly scoped.

**The front page and the page it links to disagreed on a count.** The front page said
"three groups already train networks"; the landscape map counts four in that cell —
DOSED, SEED, cnn-ripple, SpikeNet. The front page had silently dropped the one that
was never retrieved. It now names four and says which one is on bibliographic record
alone, which is both accurate and the more modest claim.

## What would validate it, and where it generalises

Every claim added here is checkable against a named source: the detector's own
docstring, the Zenodo record, the GitLab licence file, and the Nature citation.
None rests on this repo's own prose. The generalisation worth keeping is the
first-order one: **an attribution fix that removes a name has not finished until the
derivation is stated somewhere the same reader will reach.** The rename was correct
and incomplete for three days, and nothing in the tree could have noticed — the
README was right, the code comment was right, and the public page was the only place
the two failed to meet.
