## Findings
Columns: location · issue · severity · suggested fix · verifiable against a source

1. **F1 (S3, extract 61).** "That is the case for setting K per recording (MAHICE, the expert-reviewed threshold)." · There are three misreads in one line. (a) MAHICE is the project's own coinage, and GLOSSARY:163–169 requires it to be spelled out on first use and attributed. (b) "Expert-reviewed" credits the threshold with an external expert review. The glossary describes something different: a person sets K while reviewing. (c) The line implies MAHICE's K handles background. GLOSSARY:196–201 says MAHICE's K is one *percentage* of ROIs per review, held across recordings. At a fixed 33 cells that is a fixed absolute K, which is exactly what the bullet just showed failing. · **high** · Cut the parenthesis. If the point is kept, state it as work done: "a threshold that follows the background. MAHICE (machine-assisted human identification of coordinated events, Tony's term) sets K as one percentage of ROIs, so it does not do this either." · yes (GLOSSARY.md 163–204)

2. **F2 (S1 line 13; S5 line 130; S10 table line 247).** "Murderboarded, 11 roles and blind verify rounds", "a reviewer estimated", "a reviewer's test". · A later report quoting these will be read as review by colleagues; the reviewers were Claude agents. · **medium** · "Reviewed by 11 Claude review agents (no human reviewer)" and "a review agent estimated…". · yes (run record exists; the page itself says the sessions are Claude)

3. **F3 (Fig 3 B; S7 lines 189, 197–199).** The figure shows 100 % flagged at M = 1, with the annotation "every recording reads 'uniform-only'" beside it. The text says "flags every recording while E/M ≥ 1". · "Flagged" in `membership_limit.py:89` means any verdict other than "no-assembly". That count includes "uniform-only", which the page itself calls the case the margin null *cannot* see. The caption's "both nulls and both statistics" makes a reader take "flagged" to mean both nulls rejected. A reader therefore concludes the verdict detects the single assembly, which is false. "Uniform-only" is also never defined. · **high** · Plot structure-beyond-rate and uniform-only as separate series, or define "flagged" as "either null rejects" in the caption and the text. Drop the code identifiers from the caption. · yes (`assembly.py:108–131`, `membership_limit.py:81,89`)
