## Conventions I used (project may tune these — stating them so the numbers are checkable)

This is a scrolling HTML report, not a deck, so the per-slide 40-word rule does not transfer. I used:
- **largest single text block > 60 words** → flag (a wall is a wall on any medium);
- **a results or methods section with no figure** → flag;
- **two or more consecutive figure-free sections** → flag;
- **figure area < 50% of its own section's area** → flag;
- figure width < ~90% of the text column → flag (**not triggered**: the figures render at their intrinsic 900 px inside a 948 px column, 95%, with no auto-shrink. The 13.3-in-slide failure mode is *absent* here — the defect on this page is page share and ink density *inside* the figure, not width).
