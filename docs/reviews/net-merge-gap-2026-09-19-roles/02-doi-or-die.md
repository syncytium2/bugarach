- **Nadeau–Bengio is correctly attributed, correctly described and correctly applied.** Crossref on `10.1023/A:1024068626366` returns exactly Claude Nadeau & Yoshua Bengio, *Inference for the Generalization Error*, **Machine Learning 52(3):239–281, 2003** — the report's metadata is exact to the issue and page range. **Origin traced:** the root is the same two authors' NIPS 12 (1999) paper of the same title (`papers.neurips.cc/paper/1661`), expanded into the 2003 journal article; same authors, so no laboratory-attribution risk. **Forward trace:** the carry to k-fold is Bouckaert & Frank (2004), which the parent report already cites — the addendum wraps the report's implementation, not the paper, so there is no third-party tool whose authors' later applied work could be the closer prior art. The **factor is right**: the corrected resampled *t* multiplies the variance by (1/K + n₂/n₁); with K = 4 folds and a test set one third of the training set, *t* scales by √((1/4)/(1/4+1/3)) = **√(3/7) = 0.65465 → 0.655**. Code agrees: `tools/tune_net_merge_gap.py:78` `NB_FACTOR = math.sqrt(3 / 7)`; `tools/build_fair_comparison_report.py:78` "the variance's 1/J becomes 1/J + n2/n1".
