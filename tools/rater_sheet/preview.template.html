Rater sheet: local preview

This page runs the same sheet the Qualtrics survey runs, on the pilot's synthetic rows, in a new random order on every load. Nothing is sent anywhere. At the end you can save the answers as a CSV laid out like a Qualtrics export, to test the scoring.

What to do. Each row is 15 minutes of activity, one cell per lane, with a tick at each calcium event. Some moments have many cells becoming active together: those are coordinated events. Zoom in, click each one you see, then say how real the row looks. If two events sit close together, mark both. Some rows have no coordinated events. This 30-second walk-through shows every control.
